# Handoffs

Each contributor has one file here, named after them (`josh.md`, `<name>.md`). The file is written by that contributor's AI agent and is read by everyone else's.

## Rules

- **Read all of them** before starting work. The **Needs from others** sections are how we ask each other for things.
- **Write only your own.** If you need something from someone, put it in your own **Needs from others** section, addressed to them by name, or to an area (`backend`, `auth`, `database`, `infra`, `ops`) if nobody owns it yet.
- When you finish something another contributor asked for, add it to your **Done for others** section with a PR or commit link. The contributor who asked removes it from their list.
- Keep entries short and concrete: what's needed, exact names (paths, routes, env vars, IDs), and by when.

## Adding a contributor

Copy [`_template.md`](_template.md) to `<your-name>.md` and fill it in.
